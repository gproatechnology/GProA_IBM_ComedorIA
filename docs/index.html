¿Qué es?

Sintel es un sistema de gestión de cafetería corporativa con asistencia AI para entornos IBM. Permite a los empleados seleccionar menús de manera intuitiva a través de kioscos táctiles, optimizando la experiencia de comedor en oficinas modernas.

Arquitectura

Frontend

HTML5/CSS3/JS vanilla, responsivo y optimizado para kioscos táctiles.

Backend

Flask con Blueprints, SQLAlchemy y PostgreSQL para escalabilidad enterprise.

AI

Integración con IBM watsonx para recomendaciones personalizadas y análisis de datos.
